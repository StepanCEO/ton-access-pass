# TON Access Pass — спецификация

Telegram Mini App, который продаёт доступ в закрытый канал за TON. Оплата и срок
доступа хранятся в блокчейне: любой может проверить подписку, не доверяя бэкенду.

## Как это работает

1. Пользователь открывает Mini App из бота, видит цену и срок доступа.
2. Подключает кошелёк через TON Connect и подтверждает платёж.
3. Транзакция уходит в контракт `AccessMaster` с сообщением `Subscribe { telegramId }`.
4. `AccessMaster` проверяет сумму и разворачивает (или продлевает) контракт
   `Subscription` этого пользователя — по одному на Telegram ID.
5. Бэкенд читает `expiresAt` из `Subscription` и выдаёт ссылку-приглашение в канал;
   по истечении срока бот убирает пользователя из канала.

## Контракты (Tact)

**AccessMaster** — один на канал.
- Хранит: владельца, цену, срок доступа в секундах, число продаж.
- `Subscribe { queryId, telegramId }` — оплата. Нужно приложить не меньше
  `price + 0.05 TON` (0.05 уходит на развёртывание и хранение `Subscription`).
  Меньше — транзакция отклоняется, деньги возвращаются.
- `Withdraw { amount }` — вывод выручки, только владелец; на контракте остаётся
  0.1 TON на хранение.
- `SetPrice { price }` — смена цены, только владелец.
- Get-методы: `price`, `period`, `sales`, `owner`, `subscriptionAddress(telegramId)`.

**Subscription** — по одному на пользователя.
- Хранит: адрес мастера, Telegram ID, `expiresAt` (unix-время), последний плательщик.
- `Extend` принимает только от своего `AccessMaster`. Продление считается от
  `max(сейчас, expiresAt)`: оплата заранее не сгорает, а прибавляется к сроку.
- Get-методы: `expiresAt`, `isActive`, `telegramId`.

Почему контракт на пользователя, а не общий словарь подписок: в TON хранение и газ
растут с размером состояния. Отдельный маленький контракт на пользователя — стандартный
паттерн масштабирования (так устроены jetton-кошельки).

## Безопасность и ограничения

- Оплатить можно за любой Telegram ID (например, в подарок). Привязку к реальному
  пользователю делает бэкенд по проверенным `initData` Telegram.
- Mini App отправляет `price + 0.06 TON`: 0.01 — запас на случай, если кошелёк вычтет комиссию
  пересылки из суммы (так и случилось на первой оплате в testnet). Излишек остаётся выручкой.
- Только testnet, пока проект демонстрационный. Приём криптовалюты в оплату на
  mainnet требует проверки законодательства страны продавца.
